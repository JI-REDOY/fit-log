## About FitLog

**FitLog** is a modern, dark-themed gym companion that helps you browse workouts, build a focused daily plan, and stay consistent. Pick a lift, lock it into today's plan, and watch the week's work add up.

The entire app uses a near-black background with neon lime (`#CCFF00`) accents for a clean, no-nonsense gym experience.

---

## Technologies Used

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Context API** for global state management
- **localStorage** for client-side persistence
- **Google Fonts** — Oswald (headings) + Inter (body)

---

## Key Features

| Feature | Description |
|---------|-------------|
| **Workout Library** | Browse 12 workouts from the API in a responsive 3×4 grid with images, category tags, and stats. |
| **Workout Details** | Dynamic pages with full specs, numbered instructions, and action buttons. |
| **Today's Plan** | Add up to 5 workouts to your daily plan with live counters. |
| **Save for Later** | Bookmark workouts and access them from the Saved tab. |
| **Toast Notifications** | Every action shows a quick toast message (add, remove, save, done). |
| **Sort Functionality** | Sort your plan by duration, calories, or rating with asc/desc toggle. |
| **Search** | Search workouts in both the Library and My Plan by name or muscle group. |
| **localStorage Persistence** | Your plan and saved workouts survive page reloads and browser restarts. |

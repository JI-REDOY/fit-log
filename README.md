# FitLog

FitLog is a dark-themed workout library and daily planner built with Next.js. Browse workouts, add them to today's plan, and save your favorites for later.

## Technologies Used

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Context API
- localStorage

## Key Features

1. **Workout Library** — Browse 12 workouts from the API in a responsive grid with images, category tags, and stats.

2. **Workout Details** — Dynamic pages with full specs, instructions, and action buttons.

3. **Today's Plan** — Add up to 5 workouts to your daily plan with live counters.

4. **Save for Later** — Bookmark workouts and access them from the Saved tab.

5. **Toast Notifications** — Every action shows a quick toast message.

6. **Sort Functionality** — Sort your plan by duration, calories, or rating.

7. **localStorage Persistence** — Your plan and saved workouts survive page reloads.
